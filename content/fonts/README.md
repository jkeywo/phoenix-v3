# Menu title font

Both main menus display **Against the Stars** in UnifrakturCook Bold, a gothic/blackletter title face. Controls retain Lato for readability.

The unmodified `UnifrakturCook-Bold.ttf` and its accompanying `UnifrakturCook-OFL.txt` were retrieved on 18 October 2026 from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/unifrakturcook). The SIL Open Font License 1.1 permits embedding and redistribution with this software; the copyright notice and full license accompany native and web distributions.

Font SHA-256: `ea002fa9c65f1a612af100e00d87ab65f16381f450020ec3d021f3dbf79a6dcd`.

The font is bundled locally, including in the WASM filesystem. The HTML menu uses the same file without contacting an external font service.
