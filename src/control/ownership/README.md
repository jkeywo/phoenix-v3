# Human Console participation

`phoenix.control.ownership` owns claim occupancy, Away policy and supplemental human-seeking Console assignment. `ownership.cppm` defines the small compiled participation model; `ownership.cpp` resolves actual and preferred operators in stable claimant order.

The World supplies immutable layout metadata and separately checks physical availability and Controller authority. Read-only claim/Away views preserve existing checkpoint encoding; all mutations pass through `ConsoleOwnership`. Clearing transport claims leaves accepted operations and Away policy intact. Relevant integration: Console handover, crew claims, capture and session recovery.
