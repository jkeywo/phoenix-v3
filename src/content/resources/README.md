# Catalogue resource adapters

Read compiler.cppm and types.cppm first.

Resource/recipe catalogue lookup, fitted power bindings and physical stock declarations.

Dependencies: Generic stock/network/processor definitions plus explicit domain compilers.

Ownership: Live allocation, reservations, transactions and work accounting remain in resources runtime modules.

Validation: Stock, processor, power-allocation and content integration cases. These are existing integration surfaces; this guide does not claim they have run for a particular revision.
