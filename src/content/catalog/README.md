# Catalogue model

Read types.cppm (phoenix.content.catalog) first.

Catalogue records, base metadata, inherited definition resolution and knowledge composition.

Dependencies: Pack and compiled Controller-binding contracts plus generic definition modules.

Ownership: Catalogue values own authored tables and compiled caches; verification is above this module.

Validation: Content dependency, override, inheritance and draft resolution cases. These are existing integration surfaces; this guide does not claim they have run for a particular revision.
