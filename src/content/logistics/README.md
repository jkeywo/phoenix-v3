# Logistics definitions

Read compiler.cppm and types.cppm first.

Craft, docking, transport, material placement and supply definitions.

Dependencies: Resource definitions and explicit physical/compiler collaborators.

Validation: Craft, docking, cargo and logistics integration cases. These are existing integration surfaces; this guide does not claim they have run for a particular revision.
