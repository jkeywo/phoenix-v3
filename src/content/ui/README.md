# Authored UI layouts

Read types.cppm (phoenix.content.ui) first.

Layout compilation/resolution, theme lookup, structural availability and tab selection.

Dependencies: Catalogue and portable authored definitions; no UI framework.

Ownership: UiTabs owns its selected authored page; transient readiness and authority remain elsewhere.

Validation: Content UI layouts, summary bindings, Console model and input/semantic cases. These are existing integration surfaces; this guide does not claim they have run for a particular revision.
