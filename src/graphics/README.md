# Graphics family

Read [geometry](geometry/README.md) for pure camera/facing math, then [assets](assets/README.md), [scene](scene/README.md), [radar](radar/README.md) and [audio](audio/README.md).

The GPU modules consume authorised presentation records and immutable content. They do not own sessions, application screens or physical simulation. Audio policy and geometry have separate targets so headless contract checks do not acquire device/rendering dependencies.
