# Knowledge and permitted observations

Read generic `records` first, `consoles` for authored ownership/publication integration, then `projections` for immutable decision/presentation snapshots. `read-models` independently compiles the allowlisted encoders/decoders shared by World, UI and remote sessions; it links only foundation contracts.

Authoritative knowledge and snapshot ownership never become a client-side World dependency. Physical mechanisms ingest legitimate observations; Controllers and GUI consume the same permitted facts. Definitions and bindings are compiled from `content/knowledge`; continuation and scoped evidence remain with the runtime owner.
