# Permitted projections and snapshot lifetimes

`phoenix.knowledge.projections` owns the frozen decision frame and presentation cache. `decision.cppm` composes the portable domain records; `projections.cppm` defines the read/freeze interfaces; `projections.cpp` owns mutation and cache invalidation. It has no World, Flecs, graphics or device access.

World composition captures legitimate domain observations, then freezes command sections, Console evidence and addressed inboxes before Controllers run. Presentation is cached independently until a mutation. Neither cache is saved; restore reconstructs it. Decision consumers read `DecisionObservation`, which contains no presentation JSON. Presentation readers encode their permitted records separately. Relevant integration: Controller runtime, knowledge scoping, session handover and continuation.

`phoenix.knowledge.decision_machinery` owns portable machinery observations, fixed telemetry field IDs and typed ability/process facts. Scoped native producers populate these records directly; JSON encoders preserve presentation and wire boundaries separately. Property values keep their declared state-tree type, and finite process facts retain missing-detail semantics. Telemetry names are resolved at loading or explicit serialization boundaries, then ordinary decision readers use field IDs.
`phoenix.knowledge.decision_combat` owns portable combat, scanner and inspection evidence records. Native compartment and equipment producers populate scoped snapshots directly; sensor samples capture typed decision metadata when evidence is produced or restored. Contact, inspection and sensor report payloads are decoded only at record admission, with invalid latest reports retaining their stream identity so older evidence cannot revive. Presentation encoders retain the existing wire shapes.

`machinery_decision_from_json` is an explicit debug/provider projection boundary decoder; ordinary captures populate typed machinery facts directly. It preserves absent process details and accepted-intent semantics while accepting the existing diagnostic presentation format.

`phoenix.knowledge.decision_personnel` owns teams, patients, local facilities, repair needs and personnel records. `phoenix.knowledge.decision_travel` owns docking, logistics and FTL records, with explicit presence flags for unavailable feeds. `phoenix.knowledge.decision_operations` owns portable away/craft records and their canonical presentation serializers; the lower target lets Away produce snapshots without importing mutable projection runtime. `phoenix.knowledge.decision_psychic` owns scoped choir seats and fading contacts.

Knowledge admission and restore populate immutable typed contact, inspection and sensor payloads. Projection caches contain only their visible records; Controller restriction removes other recipients and their cached payloads together. Equal-version field merges advance a transient projection generation without changing wire or checkpoint identities. Frozen frames retain their original generation.
