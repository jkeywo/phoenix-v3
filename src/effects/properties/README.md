# Property effects

`phoenix.effects.properties` owns modifier applications, native/custom aggregate records and checked property arithmetic. Pure preparation functions receive immutable definitions and an explicit catalogue or precompiled values. Native adapters retain target availability and ECS owner resolution.

Read `properties.cppm` and `properties.cpp` for the owned state and preparation operations. Authoritative ECS handles never enter player projections. Existing property, rules and store-effect integration cases protect contribution lifetime and transaction behaviour.
