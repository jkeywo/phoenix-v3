# Effect funding

`phoenix.effects.funding` prepares transient upkeep plans for rules, abilities and processes. It owns canonical input identities, alias coalescing, fractional work credits, fee bundles and checked work-price arithmetic. Native stores remain the resource owner's authoritative stores; plans contain addresses and quotations only.

Plan builders take immutable definitions, captured context and native continuation records. Resolution receives explicit target, equipment, property and store queries. Electrical allocation and publication are separate native schedule responsibilities; successful input resolution alone does not authorize a payment or receipt.

Plan construction, canonical input resolution and work-credit bookkeeping are integrated. Native resource admission and allocation orchestration remain contextual; the migration ledger records the verified checkpoint.
