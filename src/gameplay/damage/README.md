# Native damage policy

Start with [damage.cppm](damage.cppm).

Owns bypass remainder, geometric shield interception, ordered layers, deterministic equal-share allocation, native shield reserve updates, fault strikes, compartment failure and collision damage plans. Authored pre/post rule execution stays between native stages; the module receives frozen factors and returns actual native absorption.

No ECS, callbacks, World context, UI or network dependency. The adapter must retain rule/casualty/payload receipt order.

Validation: Existing synthetic native combat/controller/continuation cases through the production World adapter after activation. These sources are prepared privately until that integration gate.
