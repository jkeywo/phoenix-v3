# Native machinery eligibility

`machinery.cppm` exports `phoenix.gameplay.machinery`; link `phoenix_gameplay_machinery`. native_machinery_blocker checks a selected native process against its actor, typed process definition and explicitly supplied NativeMachineryState. The optional personnel definition is supplied only for recovery work.

This is a bounded eligibility service above native component/effect definitions. It receives unavailable/dormant/docked facts, not World, the complete definition map or permission to schedule phases. Effects/processes owns machinery quote bookkeeping and funding; flight, recovery and other native owners perform the resulting work.

Existing process, finite work, resource and native outcome cases exercise legitimate blockers and receipt behavior. Migration evidence records executed integration gates. A blocker result alone is not a paid-work or effect-commit receipt.
