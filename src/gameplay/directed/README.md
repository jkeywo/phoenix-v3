# Directed capability continuation

Start with [directed.cppm](directed.cppm).

Owns directed operating/targeting mode continuation, apparent-contact qualification, admitted power requirements, operation receipts and native weapon-mode mutation. Save and read-model operations use the same typed owner. Native adapters enumerate fittings, resolve catalogue/resource slots, validate observation ownership and apply admitted operations. They do not reimplement selection or receipt rules.

`DirectedMountOwner` stores only a native equipment handle; the ECS adapter resolves it against its own world. `PreparedDirectedOperation` is transient and is never checkpointed.

Validation: Existing synthetic combat/controller/continuation system cases after native adapter activation. Graphical/audio/tuning smoke remains separate.
