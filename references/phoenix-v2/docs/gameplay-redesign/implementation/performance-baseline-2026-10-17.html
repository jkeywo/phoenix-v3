Every cell is the median of six valid per-run statistics across both accepted batches. The update percentiles are not pooled percentiles. Scroll the table sideways on narrow screens.

Reference workload

Each run uses the Alliance Cruiser on all Backfill, seed 42 and 60 simulated seconds. Phase runs discard the first 300 updates and retain 3,301. Separate runs without phase instrumentation supply process wall time. All six runs from both batches contribute equally; no fastest-run selection is used.

The measured implementation includes the accepted publication-buffer optimisation. Its small Skyway cost is included in this baseline. Source, executable, content, gameplay-report and final-digest evidence remain attached to the four-candidate report.

How to use it

Compare future local runs using the same machine, workload, build profile and instrumentation. This adoption changes the reference, not the game. It introduces no new automatic timing gate or regression tolerance and does not replace the separate CI/demo baseline for Linux release/default-world runs.

These are adopted verified captures, not a fresh measurement of ongoing CI fixes or the latest working tree. Historical speed comparisons remain available as history; they are no longer the active recovery target.
