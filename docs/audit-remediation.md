# Simplification audit remediation

17 October 2026. This records the fifteen major and two minor recommendations across the original and expanded audits. Overlapping recommendations share implementations.

| Recommendation                                                     | Resolution                                                                                                                                                                                                                                                    |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Major 1: repeated pack decoding, encoding and copying              | Immutable shared `Pack`, editable `PackDraft`, direct draft verification and borrowed ZIP entry buffers. Exact original archive ownership follows the pack.                                                                                                   |
| Major 2: native/browser transport policy duplication               | Shared private `LinkPolicy`; platform adapters retain socket and WebRTC operations.                                                                                                                                                                           |
| Major 3: repeated observation and asset work                       | One permitted observation per frame; PNG verification once per referenced asset path per pass. Explicit user actions can request fresh state.                                                                                                                 |
| Major 4: duplicated widget/action vocabulary                       | Shared widget bindings and operating-action descriptors feed authoring, verification, tree compilation and runtime admission.                                                                                                                                 |
| Major 5: hashing pulls in content                                  | Foundation owns hashing, bounded file IO and secure random tokens. Blob and journal targets no longer depend on content for these.                                                                                                                            |
| Major 6: duplicated texture ownership                              | Shared RAII texture cache, with independent game/editor instances and explicit invalidation.                                                                                                                                                                  |
| Major 7: dead or misleading state                                  | Removed unused application pack storage and redundant runtime tree-entry/blob failure flags. Startup errors are displayed. `save_tree` and `network_code` remain because newer work uses them. The saved tree-entry field remains for schema-1 compatibility. |
| Major 8: duplicated build configuration                            | Shared fixture setup and inherited first-party WASM exception settings. Platform-specific target differences remain explicit.                                                                                                                                 |
| Major 9: maximum blob payload cannot be reopened                   | Blob reader budget includes record overhead; the integration test writes and reopens an exact 32 MiB payload.                                                                                                                                                 |
| Major 10: allocating transfers just to validate offers             | Metadata-only offer validation precedes cache requests; buffers are allocated for missing content.                                                                                                                                                            |
| Major 11: rewriting cache hits and copying archives                | Only downloaded/repaired packs are queued for persistence; asynchronous jobs retain immutable archive owners.                                                                                                                                                 |
| Major 12: session/fleet ZIP roundtrips                             | Shared container save/restore operations compose the in-memory state; encoding remains at external archive boundaries.                                                                                                                                        |
| Major 13: server activation depends on temporary console admission | Explicit server start/resume plus side-effect-free eligibility checks. Portable recovery still clears historical claims.                                                                                                                                      |
| Major 14: repeated action/token rules                              | Shared action parsing, range/capability rules and identifier/token predicates. Protocol and save schemas remain unchanged.                                                                                                                                    |
| Major 15: presentation state outlives its session                  | `GameScreen` owns state and resources; owner, content and lifecycle generation invalidate state, including same-pack remote epoch changes.                                                                                                                    |
| Minor 1: repeated exception flags and fixture declarations         | Foundation propagates compile/link exception settings; `phoenix_fixture` configures native and WASM fixtures.                                                                                                                                                 |
| Minor 2: repeated consensus/storage pumping                        | `DurableConsensus` owns journal opening, recovery policy, pending writes and acknowledgements. Host/fleet retain their distinct scheduling and application logic.                                                                                             |

Synthetic integration coverage exercises pack ownership and draft isolation, supported path bounds, cache reuse/repair, maximum blob persistence, admission, portable recovery, session generation and behavior-tree continuation. The complete `scripts/check.ps1` gate passed: all ten native integration cases, all WASM checks, matching native/WASM continuation traces and all five network-service cases covering live fleet recovery, client/GM admission and trusted/untrusted WSS. Formatting and whitespace checks passed. Gate output is in ignored `build/audit-final-check.log`.

The separately invoked browser/native transport smoke also passed direct WebRTC and forced relay in both directions, with empty browser diagnostics and native stderr. See [transport smoke evidence](smoke/network-transport.md). These refactors do not establish unimplemented GDD acceptance requirements, Internet deployment or hardware performance/accessibility outcomes.

Separately invoked native viewscreen, console and Workshop smoke runs exited successfully. Their inspected captures show textured billboards, radar contacts, authored controls and Workshop thumbnails/properties; logs contain no warnings/errors and record clean resource shutdown. Captures and logs are under ignored `build/audit-ui-smoke/`. These are rendering smoke observations using the training pack, not shipped-content goldens or tuning assertions.
