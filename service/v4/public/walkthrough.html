Phoenix manual acceptance

Allow about 20 minutes once builds are downloaded. Record the devices, route and results. Missing hardware remains pending; a desktop emulation does not count as a phone or screen-reader pass.

  1. Join a mixed fleet · 2 minutes. Create a two-host session. Open one browser host and launch the native executable using the second host’s arguments. Join desktop and phone stations using the code or QR.
  2. Independent controls · 2 minutes. Claim Helm and Engineering on the native bridge. Assign a gamepad to each region, or assign the keyboard explicitly. Change thrust while starting a repair. Confirm only the intended station receives each input.
  3. Knowledge · 2 minutes. Compare Science, Tactical and GM. Scan the drone at Science. The damaged-reactor finding must appear only where permitted. A payload audit is a separate automated check.
  4. AI handover · 1 minute. Release Helm to AI, then reclaim it. Hold a movement input while changing ownership or unplugging its controller. Old input must not continue.
  5. GM intervention · 1 minute. Claim GM, spawn a drone, apply damage and publish a report. Both hosts must agree. A station connection must not acquire GM authority.
  6. Loss and recovery · 2 minutes. Disconnect one of two hosts. Both simulations must pause. Restore the connection and check continuation. Repeat with a three-host fleet: two may continue; the isolated host must stop.
  7. Save · 2 minutes. Start a repair, save, then recover into a new session. Join using the new code. The unfinished repair must finish once; an old command must not become valid again.
  8. Mod kit · 4 minutes. Open the editor mod level and DA_Scout. Change a supported entity value. Validate, build the independently cooked mod, install the matching platform package and start its scenario. The base executable’s hash must remain unchanged. Reject the conflict fixture.
  9. Relay and internet · 2 minutes. Force relay and repeat an order. Then use two independent internet connections. Record the actual route from the diagnostics; “direct requested” is not proof of direct transport.
  10. Accessibility · 2 minutes. Use touch, keyboard and the physical device’s screen reader. Check labels, focus order, zoom and orientation. Record Android Chrome, iPhone Safari and iPad Safari separately. Six physical monitors require a separate check.
